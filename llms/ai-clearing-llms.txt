# AI Clearing

> AI-native construction progress tracking and quality control. AI Clearing turns drone imagery,
> ground-level mobile capture, CAD/BIM models and project schedules into automated progress,
> productivity and quality analytics for contractors and asset owners in solar, pipelines,
> transmission, highways, railways and airports. Founded 2020. HQ Austin, Texas; R&D center in
> Warsaw, Poland.

Provenance: generated 2026-09-13 by the API Evangelist enrichment pipeline from this repository's
apis.yml and probe artifacts. AI Clearing does not publish an llms.txt of its own
(https://www.aiclearing.com/llms.txt returns HTTP 404). This file is a third-party summary, not a
document served by the company.

## API surface

AI Clearing publishes **no public API**. As of 2026-09-13 there is no developer portal, no API
reference, no SDK, no CLI, no MCP server, no A2A agent card and no machine-readable contract
(OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, WSDL or OGC GetCapabilities) on any host the company
operates. Contract discovery was run against the marketing site, the CORE application host and the
documentation host; see well-known/ai-clearing-well-known.yml for the full probe record.

- The CORE customer application (https://core.aiclearing.com/) is a React single-page app. It
  answers HTTP 200 with the same 867-byte shell for any unknown path, and HTTP 403 from a
  Cloudflare bot challenge on API-shaped paths. It is a customer login, not a public API.
- https://docs.aiclearing.com/ resolves (Oracle Cloud, 129.158.44.122) but does not answer public
  requests: one JavaScript app shell arrived before the connection dropped, and every subsequent
  request timed out or was refused.
